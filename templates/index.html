Production REST API Architecture

Full-featured API tracking personal income and expenses with customizable categories, automated recurring entries, and strict per-category monthly budget limits. Designed for multi-tenant data isolation via JSON Web Tokens, ORM-level analytical aggregations, and high-performance Pandas CSV reporting.

🔒

JWT User Isolation

Every endpoint is scoped to request.user. Users can never view or modify foreign transactions, budgets, or categories.

📊

ORM aggregate() & annotate()

Computes instant monthly totals, net savings, savings rate, and category spending distributions directly in the database engine.

🐼

Pandas CSV Export

Transforms filtered transactions and breakdown reports into clean, standard RFC 4180 CSV attachments via Pandas DataFrame streams.

🔄

Automated Recurring Plans

Daily, weekly, monthly, and yearly recurring entries processed automatically via API action or Django management command.

📖 REST API Endpoints Quick Reference
Method Endpoint Auth Description
POST /api/auth/register/ None Register user with username, email, password, and generate default categories
POST /api/auth/login/ None Obtain JWT Access & Refresh token pair
POST /api/auth/refresh/ None Refresh JWT access token
GET, POST /api/transactions/ Bearer JWT List user transactions (supports filters: date range, category, amount, recurring)
GET /api/transactions/export-csv/ Bearer JWT Export filtered transactions as downloadable CSV using Pandas
GET, POST /api/categories/ Bearer JWT User-scoped income and expense categories
GET, POST /api/budgets/ Bearer JWT Category budget limits per month/year with spent & exceeded calculations
GET /api/budgets/status/?year=2026&month=10 Bearer JWT Overview of all active budgets and spending alerts for specified month
GET, POST /api/recurring/ Bearer JWT Recurring income & expense plans (daily, weekly, monthly, yearly)
POST /api/recurring/process-all/ Bearer JWT Process all due recurring occurrences into real transactions
GET /api/analytics/monthly-summary/?year=2026&month=10 Bearer JWT Monthly spending, income & savings summary via Django ORM aggregate()
GET /api/analytics/category-breakdown/?year=2026&month=10 Bearer JWT Category-wise breakdown via Django ORM annotate()
GET /api/analytics/category-breakdown/export-csv/ Bearer JWT Category spending breakdown CSV export powered by Pandas

Sample cURL Request with JWT

curl -X GET "http://127.0.0.1:8000/api/analytics/monthly-summary/?year=2026&month=10" \ -H "Authorization: Bearer <YOUR_ACCESS_TOKEN>" \ -H "Accept: application/json"
